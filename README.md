# MAX NOTE

（原名「错题练习站」。）

只给自己用的手机刷题网站（Cloudflare Workers + Hono + D1（照片也存 D1，不需要 R2））。网站里的助手 Max 用 Cloudflare Workers AI（免费额度），再加你在网页里填的任意 OpenAI 兼容模型（DeepSeek / 通义 / 智谱 / Kimi…）；出题、批改、总结也可由 claude.ai 通过 MCP（阶段二）完成。

当前进度：阶段一（网站）、阶段二（`/mcp` + OAuth）均已完成。

## 部署步骤（阶段一）

1. `npm install`，`npx wrangler login`
2. 部署（会自动执行 D1 迁移）：`npm run deploy`
3. 设置登录口令：`npx wrangler secret put PASSCODE`
   （或控制台 Worker → Settings → Variables and Secrets 添加 `PASSCODE`）
4. 导入几道测试题（可选）：`npm run seed:remote`

> 用 Cloudflare 的 Git 集成（Workers Builds）时，Deploy command 填 `npm run deploy`，口令在控制台添加。

## 连接 claude.ai（阶段二）

MCP 地址：`https://<你的 Worker 域名>/mcp`（例如 `https://lxb.maxcc.cc.cd/mcp`）

1. claude.ai → 设置 → 连接器 → **添加自定义连接器**
2. 名称随意（如「MAX NOTE」），URL 填上面的 `/mcp` 地址，保存
3. 点连接，会弹出授权页，输入网站的 `PASSCODE` 并点「允许」
4. 对话里 Claude 只用 3 个工具：
   - `get_inbox`：新照片 + 待批改作答
   - `save`：一次写入——`grades` 批改、`wrong` 原错题、`questions` 新题、`organize` 改分类、`summary` 总结、`retract` 撤回已推送的题（题号如 `数学3`，或 `"last"` 撤上一批整批；有待批改作答的题不撤）；`plan` 排期（`[{q:["物理3"],d:"2026-10-14"}]`，`q` 可写 `"last"`）；题目本身也可带 `due`；`def` 给本批题共用的科目/章节；`type` 可省（自动推断）
   - `get_data`：`kind=records` 作答记录 / `kind=bank` 题库清单（TSV）

省用量设计：工具少且说明短；一轮通常只要 get_inbox + save 两次调用；作图答案转成文字描述（坐标单位=格），只有手绘才附图；照片压到 1280px。

OAuth 的令牌存在 KV（绑定名 `OAUTH_KV`）。`wrangler.json` 里没写 KV id，首次 `wrangler deploy` 会自动创建；若构建报 KV 权限错误，手动在控制台建一个 KV，把 id 填进 `kv_namespaces`。

典型用法：
- 拍照上传错题 → 对 Claude 说「处理收件箱」→ 它整理错题、出同类题推送到「今日练习」
- 你做完交卷 → 对 Claude 说「批改并总结」→ 它批改简答、统计分析并写总结

## 模型接入（密钥在网页里填）

打开任意页面右下角 Max 悬浮球 → 齿轮 → **接入模型**：选服务商（DeepSeek / 通义千问 / 智谱 / Kimi / 自定义）、粘贴密钥、保存。保存时先发一句话试通，不通不保存。
- 密钥存在 D1（`meta` 表），**不用在 Cloudflare 后台加变量**；之所以存服务器而不只放浏览器，是因为交卷批改、每天凌晨整理这些后台任务没有浏览器在场。读取接口只返回尾号，密钥不会再传回网页。
- 接口地址就是 OpenAI 兼容的 base（如 `https://api.deepseek.com`），请求发到 `{base}/chat/completions`；模型名、深度思考模型可改。
- 默认「优先用我的模型」：批改、讲题、出题、整理错题、首页建议、错题诊断都先走它，出错/额度用完才轮到 Cloudflare 免费额度；关掉就恢复成 Cloudflare 优先。每天最多用 80 万 token。
- 旧的 `DEEPSEEK_API_KEY` 变量仍然认（网页里填的优先）。

## AI 学习台（/study，底栏第二个）

- **掌握度地图**：按 科目›考点 统计近 60 天答对率（平滑后），分 薄弱 / 练习中 / 熟练 / 未练，每行「学」「练」。打开页面不花额度。
- **今日学习计划**：AI 根据掌握度排 3-5 步（先讲后练、穿插回顾）；没接模型或额度用完时用规则排，页面照样能用。「↻ 让 AI 重新排」才花额度。
- **知识点微课**：点「学」流式生成一节微课（一句话讲清、核心知识、例题、易错点——结合你真实的错因、自测），每个考点缓存 7 天，「没懂，换种讲法」重讲。
- **AI 助教答疑**：对话时 Max 能看到你的掌握度和错因（`ctx.study`），回答针对你；可开深度思考、联网搜索；回答里的「练」按钮直接开练。

## 题库永久保存 · 题库全集（/library）

- 题目**不再自动删除**：隐藏超过 30 天的、一次做对的、错题文件夹每天凌晨清空的，都只是变成「已归档」，留在题库里。只有你手动点「删除」或让 Max/Claude 清理才会真删。作答记录一直保留。
- 题库页的「题库全集」：全部题的搜索（题干/考点/解析）、按科目和状态（在用/已隐藏/已掌握/已归档）筛选，展开看答案和解析，「放回练习」「练这题」「打印所选」。A4 排版页的选题也多了「全集」来源。

## iOS App 的缓存与同步

- **网页层**：GET 接口成功的结果存在本机（最近 40 个），没网时先显示上次的内容（页面顶部提示一次）；写操作（交卷等）没网会提示联网后再试。
- **App 层**：页面和脚本走系统缓存，没网时先用缓存页面；题库全集同步到本地 SQLite（`/api/library/sync`，带 ETag，没变化只回 304，登录状态复用网页 Cookie），启动、回到前台时检查；连不上服务器时，「无法连接」卡片里有「离线题库」，可搜索、看答案和解析。
- 该请求的照常请求：做题、交卷、批改、Max 对话、打印排版数据都实时走服务器。

## 练习册模式

- 没有考试倒计时、没有时限（首页、Claude 的 `save`、Max 动作里的「设考试」都去掉了）。
- 「清空历史记录」（设置 → 工具，或对 Max 说）：删作答记录、总结、Max 缓存回答，**题库和错题本保留**——做错过的题会固定成错题，等你重做；连续练习天数归零。先数一数、确认才删。
- 错题本按 科目 › 章节 › 考点 分组，每组一个小标题（几题 + 重做这组）；顶部「一键整理」= Max 分析错因 → 合并同义考点 → 重写总结；「学习诊断」让 Max 说最薄弱的考点和练法。

## 页面与分类

- 首页：今日练习、Max 建议、拍照上传、各科概览；底部导航 首页 / 题库 / 错题本（线条图标）
- 题库、错题本：按 科目 → 分类（章节）→ 考点 分组，点题目看答案、解析和历史作答，可「练这组」「重做」
- 题型标签：Claude 出题只给 `tag`（选择/填空/计算/解答/证明/作图/函数/电路/简答），网站自动定题型和画板（计算、解答→计算板；证明、作图→方格；函数→坐标系；电路→电路图板）；`organize` 可改标签。简答题也可按科目手动开画板，可同时开多个：
  - 🧮 **计算解答板**（`calc`，数学/物理）：横线纸手写板，和作图板同一套代码（画笔、颜色粗细、文字、橡皮点/划删、撤销重做、放大）；「＝算式」写完自动出得数（小数自动化成分数、根式化简如 4√3；画板上的分数写成竖式 ¾，后面附小数），方程自动解（如 x²-5x+6=0 → x=2，x=3）；🧮 计算器可把结果贴到画板；可展开「打字整理步骤」（MathLive 公式输入，初中定制键盘）。交卷发文字，手写了才附图
  - 物理 🔌 **电路图板**（`circuit`）：电源、开关（点一下通断）、灯泡、定值电阻、滑动变阻器、电流表、电压表、电动机、电铃、LED；导线自动折直角，三线交汇自动画连接点。交卷时代码算出网表（各元件接哪两个节点）并提示并联、短接、断头
  - 数学 📐 **几何函数板**（`coord|grid`，其它科目也用它）：在题目下方直接显示作图板，方格常驻。格点吸附，按住时显示十字辅助线和坐标气泡（手指挡住也能看准，松手落点）；撤销/重做在画板正上方；直线/射线自动延长到边缘带箭头；标点时起名并自动写坐标（如 A(1,-4)）；可在画板上直接打字；另有圆、多边形、平滑曲线、垂线、平行线、函数自动画图、画笔、橡皮、虚线、撤销/重做
- 分类由 Claude 维护：可对它说「按我 Notion 错题库的分类整理题库」，它用 `get_question_bank` + `organize_questions` 调整，也可以把错题同步到 Notion（网站本身不连 Notion）

### Max 助手（悬浮球）

- 输入框上面两个标签，点一下开、再点关（只记在当前标签页）：
  - **深度思考**：只用你接入的思考模型（DeepSeek 默认 `deepseek-reasoner`，设置里可改），想得更深更慢；没接入模型或当天额度用完时会提示。
  - **联网搜索**：先搜网页再回答，结尾写来源。依次试 Tavily（设了 `TAVILY_API_KEY` 密钥才用，最稳）→ Bing 网页 → DuckDuckGo 网页 → 中文维基；都不行时如实说没搜到。
- **练题**：Max 回答里的「练：科目/考点」按钮 → `/quiz?topic=科目/考点`。题库里有同类题（考点、章节或题型标签匹配）就直接练；没有就让 Max **现场出 10 道以内**的临时题（只出选择/填空）：不进题库、不进错题本和做题记录；答完当场判分，错了只提示，可点「让 Max 分析」（把这道题和你的答案带给 Max）。
- **清理题库**：对 Max 说「把集合的题删了 / 清掉做过的」，它会给出「清理题库：科目/考点」按钮，点了先数一数、你确认才删（只删还显示着的题；待批改的、做题记录都保留）。

## 题图（Claude 的画板）

Claude 推题时可带 `fig`（模板里有写法）：
- **画板描述**（几何、函数、受力/光路）：`{axes?, grid?, x?, y?, items:[…]}`，单位=格、y 向上；点起名后线段/多边形可直接用名字（`{t:"poly",pts:["A","B","C"]}`），还有直角 `right`、角弧 `angle`、函数 `fn`、文字 `text`、力/光线/镜子等。网站用作图板同一套画法画出来。
- **电路图**：`{circuit:true, items:[…]}`，格点坐标（y 向下），元件（电源、开关、灯泡、电阻、滑动变阻器、电流表、电压表、电动机、电铃、LED、保险丝）+ 导线，用电路图板同一套符号；导线不在一条线上自动折直角，三线交汇自动画连接点。
- 写法省字：点先在 `P:{A:[0,3],B:[0,0]}` 里定义一次，`pts:"ABC"`；`d`/`on`/`axes` 写 1 也行；单引号、结尾多余逗号也能认。
- **SVG**（实验装置、图表）：`fig:{svg:"<svg …>"}`，带脚本/事件的会被拒掉。
- 位置：题干正下方、选项和画板之前；按内容自动裁边居中，宽度不超过容器、高度不超过半屏，点的名字放在背离图形中心的一侧；点一下全屏放大。画板题滑到画板时，题干浮窗（平板是左栏）里也有题图。结果页、错题本详情里也显示。
- Max 看不到图：批改和讲题时附一段题图的文字描述。`organize` 可带 `fig` 给旧题补图。

## 新题排期

Claude 推题时每题可带 `due:"YYYY-MM-DD"`（哪天开始做，省略 = 今天），已推的题可用 `plan` 改排期。网站只把到期的题放进今日练习、按科目练和 Max 的推荐；没到期的在题库里显示「X月X日做」，不算「未做」。24 小时的显示期从开始做的那天算起。

## 后台任务（为什么不会再卡住）

模型慢的活（交卷后 Max 批改、Claude 题的初评、整理错题、整理分类、复核新题、首页建议、错题总结）不在网页/Claude 的请求里等：先存进 `jobs` 表，请求里马上试跑一次，没跑完（平台在请求结束后只给 30 秒收尾）由**每分钟的定时任务**接着做（定时任务可以长时间运行，被切断的任务 45 秒后会被接手，最多试 3 次）。结果存进库，网页轮询/自动刷新就能看到。批改被切断卡在「批改中」的，下一轮批改任务会放回去重批（不用等到凌晨）。模型调用的超时按要写多长算（20~90 秒），到点真的中止，不白花额度。

## Max 网站动作

学生让 Max 做事时（「清空标记」「清空错题文件夹」「清空历史记录」「整理错题」…），Max 回答里给 `[[做:动作]]` 按钮。点了先数一数、弹确认框写明数量，确认后才执行，做完刷新页面。动作列表在 `src/actions.ts`：清空标记、清空错题本、清空错题文件夹、清空照片收件箱、清空总结、清空历史记录、整理错题、整理分类。不做：整站清空（删题用「清理题库」按科目/考点）。

## Max 画图

Max 讲几何题、函数、受力、电路时，回答里会带 `[[图:{…}]]`，网站用同一个画板画在气泡里（点一下放大）。省用量：画图说明只在问题和图有关时才发给模型（平时系统提示不变长），也只在这时多留 400 token 输出；画图组件平时不加载，回答里一出现「[[图」就提前加载，写完马上画，同一张图只画一次。

## Max 看图

Max 输入框左边的图片按钮（也可以直接粘贴图片）：拍题目、作答、笔记发给 Max。先用 Cloudflare 看图模型（Llama 4 Scout，备用 Mistral Small 3.1）把图转写成文字，再和问题一起正常回答（深度思考、联网也能用）；转写会留在对话里，追问也知道图里是什么。

## 错题 → Notion 笔记（不用 AI）

做错题后，结果页、错题本详情、Max 临时练习里会出现「Notion 笔记：xx」按钮，Max 讲错题时也会给。网站按「科目 + 考点关键词」查一张**对照表**（存在 `meta.notes`，源文件 `seed/notes.json`），越长的关键词越准；没有具体命中就给这一科的资料页。**不需要任何配置**：表由 Claude 读 Notion 后写入，以后新增笔记页，对 Claude 说「更新 Notion 笔记链接」，它会重读 Notion 并 `save({notes})` 整表替换（`s` 科目、`k` 考点关键词、`t/u` 标题和链接，不写 `k` = 这一科的兜底页）。

可选：Cloudflare 加密钥 `NOTION_TOKEN`（Notion 内部集成密钥，并把笔记页「连接」给它），对照表没命中时会再按考点名搜 Notion 页面标题。

反过来：Notion 考点页放链接 `https://你的域名/quiz?topic=科目/考点`，直达站内同标签题（没有就让 Max 出临时题）。

## 题库生命周期（自动精简）

- **题库时效**：题目出现超过 **24 小时就隐藏**（题库、错题本、今日练习、Max 都不再显示），不管做没做、是不是错题；**没重做的错题加长到 48 小时**；错题重做做对 → 放进「错题文件夹」（不受时效限制，攒满 20 道发给 Claude）。隐藏满 30 天后每日定时清理才真删，做题记录一直保留
- 题目状态：`active` 在用 / `mastered` 错题重做做对（错题文件夹）/ `done` 第一次就做对（隐藏）；done 的 30 天后自动删
- 错题本分「复习中 / 已掌握」两页，每题可「删除」「标为已掌握」；删题不删作答记录（attempts 冗余存了 subject、topic）
- 每日 Cron（北京时间 03:17）：mastered/done 超过 30 天删题（题库里隐藏满 30 天的也清掉）；已批改作答的照片超过 30 天删除；已处理的上传超过 14 天删除；总结只留最近 30 条
- Claude 查题库（`get_data kind=bank`）默认只看复习中的题，`all=true` 才列全部；作答记录不受删题影响

## 规则速记

- 今日练习 = 到期错题 + 未做过的新题（`source=同类题`），都只含还没过时效的题
- 做错 → 进错题本，明天重做；重做做对 → 已发给 Claude 的隐藏，没发过的留在错题本（显示「重做已对」）
- 错题本里没发过的错题攒到 20 道（或满 7 天）→ 在 Claude 收件箱/保存的返回里整包附上（后端整理好错答、错因等），Claude 讲解并问是否归档 Notion；错题重做页不显示标记按钮
- 选择/填空当场判分（去空格、全角转半角，填空可有多个可接受答案）；简答标「待批改」
- 日期按北京时间
